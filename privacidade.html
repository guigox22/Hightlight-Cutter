1. Sobre este aplicativo

O Highlight Cutter é uma ferramenta de uso pessoal/interno que utiliza a API do YouTube (Google) para automatizar o upload e a publicação de vídeos em contas do YouTube autorizadas pelo próprio usuário.

2. Dados que acessamos

Para funcionar, o aplicativo solicita permissão de acesso à API do YouTube exclusivamente para:

  • Fazer upload de vídeos na conta autorizada
  • Gerenciar metadados dos vídeos publicados (título, descrição, miniatura)

Não acessamos, coletamos ou armazenamos nenhum outro dado pessoal do usuário além do necessário para realizar essas ações via API do YouTube.

3. Armazenamento e uso dos dados

Os tokens de autenticação (OAuth) fornecidos pelo Google são utilizados apenas para autorizar as chamadas à API do YouTube e são armazenados de forma segura, sendo usados exclusivamente pelo próprio usuário que os gerou.

Não compartilhamos, vendemos ou transferimos nenhum dado de acesso ou dado pessoal a terceiros.

4. Revogação de acesso

O usuário pode revogar o acesso do aplicativo à sua conta Google a qualquer momento através da página de permissões do Google: myaccount.google.com/permissions

5. Contato

Em caso de dúvidas sobre esta política de privacidade, entre em contato pelo e-mail: politicandoecortando@gmail.com
